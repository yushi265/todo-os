# todo-list-wcag-aa: UI詳細

## 操作契約

- ページタイトルを`h1`と`aria-labelledby`でmainへ関連付ける。
- ページ先頭に「メインコンテンツへ移動」リンクを置き、キーボードフォーカス時だけ表示する。
- フィルターの開閉状態とメニューを`aria-haspopup`/`aria-controls`で関連付ける。
- エラーは`role="alert"`、非同期の操作結果は`role="status"`または`aria-live="polite"`で通知する。
- ダイアログを開いたら閉じるボタンへフォーカスし、Escapeで閉じられるようにする。
- 44px未満になりうる主要操作には`min-h-11`等のタップ領域を適用する。

## コントラスト契約

`index.css.test.ts`で、defaultを含む全テーマの次の組み合わせを測定する。

- カード背景上の通常テキスト・補助テキスト
- primary/dangerボタンの前景色と背景色
- TODO/IN_PROGRESS/DONE/CANCELEDの状態表示
- HIGH/MEDIUM/LOWの優先度表示
- タグ・チップ・フォーカスアウトライン

通常文字は4.5:1以上を要求する。色トークンを変更する場合はこのテストを先に通し、目視確認だけで適合を判断しない。

## テストケース

- キーボード操作でスキップリンク、検索、フィルター、追加、モーダル閉じる操作へ到達できる。
- `role="alert"`のエラーと`role="status"`の操作結果が取得できる。
- 全テーマのコントラスト比が4.5:1以上である。
- `:focus-visible`のアウトライン規則がグローバルCSSに存在する。
