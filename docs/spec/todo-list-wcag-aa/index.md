# todo-list-wcag-aa: TODO一覧のWCAG 2.1 AA適合

## 目的

TODO一覧画面の主要操作を、キーボード・支援技術・低視力利用者が確認できる状態にする。適合確認は自動テストで再実行できる形でリポジトリに残す。

## 対象範囲

- TODO一覧の主要操作、入力、フィルター、ステータス変更、削除、テーマ設定モーダル
- キーボードフォーカス、フォーカス表示、操作名称、ライブリージョン、スキップリンク
- テーマごとの文字・状態・優先度・タグ・フォーカス色のコントラスト

## 受け入れ基準

- [x] キーボードで主要操作へ到達でき、表示中のフォーカス位置が確認できる。
- [x] 一覧にスキップリンクとmainランドマークがあり、検索・追加・フィルター・ステータス・削除の名称がプログラムから取得できる。
- [x] 状態変化や並び替えの結果を必要に応じて`role="status"`/`aria-live`で通知する。
- [x] テキスト・UI部品・状態表示の配色を全テーマでWCAG 2.1 AAの4.5:1以上（通常文字）としてテストする。
- [x] 検証コマンドと検証対象を [../../accessibility.md](../../accessibility.md) から確認できる。

## 実装・検証の正本

- UI: `src/react-app/components/` の一覧・入力・モーダル・トグル
- 色トークンとフォーカス: `src/react-app/index.css`
- コントラスト契約テスト: `src/react-app/index.css.test.ts`
- 操作回帰テスト: `src/react-app/components/*.test.tsx`
