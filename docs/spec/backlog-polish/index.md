# backlog-polish: TODO一覧の未設定バックログ実装

## 目的

`TODO.md` の優先度未設定項目のうち、favicon、Buttonプリミティブの適用、ステータス表示、変更取り消しトーストを実装する。対象は既存のReact UIに限定し、API・DB・認証境界は変更しない。

## 受入条件

- [x] **AC-1**: ブラウザのドキュメントヘッドからプロジェクト所有のfavicon SVGが参照され、既存ロゴと調和する。
- [x] **AC-2**: `src/react-app/components` のユーザー操作用ボタンが共通 `Button` プリミティブを経由して描画される。既存のラベル、ARIA属性、イベント、disabled、ドラッグ属性、44px以上のタッチ領域を維持する。
- [x] **AC-3**: TODO/IN_PROGRESS/DONE/CANCELED の全ステータスが一覧で左側アイコン付きで表示され、ステータスごとにラベル・配色・アイコンが一貫する。未完了ステータスの進行操作は従来どおり可能である。
- [x] **AC-4**: 編集モーダルの保存、および一覧のステータス変更が成功したとき、変更内容のトーストに「元に戻す」ボタンが表示される。押下すると変更前のタイトル・説明・ステータス・優先度・期限・タグへ戻り、成功通知が表示される。削除・並び替え・新規作成の復元仕様は変更しない。

## 対象外・制約

- APIエンドポイント、共有スキーマ、DBスキーマ、認証・認可は変更しない。
- shadcn/uiの外部ランタイム依存は追加せず、既存のソース所有 `Button` を拡張・再利用する。
- `prefers-reduced-motion`、既存のフォーカス表示、モバイルのFABとの重なり回避を維持する。
